# Creador De Recibos o Facturas #
Aplicación sencilla para crear, guardar e imprimir recibos de una academia de repaso. Es un único archivo (`index.html`): no hay que instalar nada, no necesita internet y no tiene cuotas.
# Qué hace #
- Rellena el recibo a partir del nombre del alumno, las horas y el precio por hora.
- Calcula el total (con IVA opcional) y escribe la cantidad en letra.
- Imprime el recibo, lo guarda como PDF o lo genera como imagen.
- Guarda los recibos creados y los muestra por nombre de alumno, con botones para imprimir, editar y eliminar.
# Cómo usarla #
1. Abre la aplicación: enlace a la página (o abre `index.html` con doble clic).
2. Escribe el nombre del alumno, las horas y el precio por hora.
3. Pulsa Guardar recibo, Imprimir recibo o Generar imagen.
4. En la pestaña Recibos guardados puedes buscar a un alumno y volver a imprimir, editar o eliminar sus recibos.
# Privacidad @
Los datos no se envían a ningún servidor. Los recibos se guardan en el navegador del ordenador donde se crean. Si se borran los datos del navegador o se usa otro ordenador, no aparecerán.
#Tecnologías# 
HTML, CSS y JavaScript, sin librerías externas.
